# Лабораторна робота №3 — Менеджер задач із глобальним станом

Vue 3 + Pinia + Vue Router.

## Запуск

```bash
npm install
npm run dev
```

## Реалізовано

- Pinia-сховище `stores/taskStore.js` (state / getters / actions) для керування задачами.
- 5 маршрутів: `/`, `/tasks/new`, `/tasks/:id`, `/tasks/:id/edit`, `/stats`.
- Список задач з фільтрацією за категорією та пріоритетом, пошуком за назвою, сортуванням за дедлайном/пріоритетом, візуальним виділенням прострочених задач.
- Сторінка деталей задачі з переходом до редагування та видаленням.
- Спільна форма створення/редагування з валідацією (обов'язкова назва, дедлайн не в минулому при створенні).
- Сторінка статистики на основі getters сховища: загальна кількість, активні/виконані/прострочені задачі, найближчі дедлайни, прогрес-бар виконання.
- Збереження стану сховища в `localStorage` через `watch` у `main.js`.
- Анімація переходів між маршрутами (`Transition` + `RouterView`).
