# Лабораторна робота №4 — Реєстрація на події (розширені можливості Vue)

Vue 3 (Composition API) + Vue Router. Без Pinia — стан організовано через composables.

## Запуск

```bash
npm install
npm run dev
```

## Реалізовано

- Багатосторінковий застосунок: список подій, деталі події, форма реєстрації (3 маршрути).
- Composables:
  - `useEvents` — список подій (спільний реактивний стан).
  - `useRegistrations` — реєстрації на події з **оптимістичним оновленням інтерфейсу**, імітацією асинхронного запиту до сервера (~15% ймовірність відмови) та **відкатом змін** у разі помилки.
  - `useLocalStorage` — універсальний composable для збереження реактивних даних у `localStorage`.
  - `useToast` — сповіщення про результат реєстрації.
- Валідація форми реєстрації (обов'язкові ім'я та email, перевірка формату email).
- Відображення списку зареєстрованих учасників на сторінці деталей події.
- Додаткові можливості Vue:
  - **Teleport** — компонент `ToastHost.vue` рендерить сповіщення в `body`.
  - **KeepAlive** — кешування `EventListView` при переходах між сторінками.
